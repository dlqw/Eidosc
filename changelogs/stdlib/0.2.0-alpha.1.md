# Eidos Std 0.2.0-alpha.1

- Migrated public standard-library source to dot Namespace paths and comma-separated ADT constructors.
- Added `Std.Either.Either[L, R]` with `Left`, `Right`, right-biased `map`, `map_left`, `bimap`, `fold`, predicates, and `unwrap_or`.
- Registered `Either` as a canonical right-biased Eidos 0.8 branch-selection subject alongside `Bool`, `Option`, and `Result`.
- Raised the embedded Std source language requirement to `0.8.0-alpha.1` and synchronized distribution metadata and release verification with the independent Std version.
