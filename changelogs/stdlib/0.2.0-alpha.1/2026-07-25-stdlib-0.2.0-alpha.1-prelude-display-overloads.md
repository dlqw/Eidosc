# Std 0.2.0-alpha.1 Prelude and overload surface

- Added the `Display` trait, primitive and core-ADT instances, and ordinary generic `print` / `println` overloads.
- Made Display-based output shared-borrow its value through the language-wide `T`-to-`Ref[T]` call conversion, so printing a non-`Copy` value does not consume it.
- Added generic `Console.write` / `write_line` overloads and retained explicit character-code operations as semantic APIs.
- Removed `print_int`, `print_float`, `print_string`, `print_newline`, `print_char`, and the corresponding type-suffixed Console families without compatibility aliases; `print` / `println` and `Console.write` / `write_line` are the only general output surface.
- Consolidated type-distinguishable Math, GameMath, Ordering, Hash, Semigroup, and Monoid families around overloads or existing trait abstractions.
- Kept explicit names only for return-only, conversion/accessor, unit-bearing, character-code, and raw/safe boundaries.
- Marked every public standard-library declaration with `export`; raw compiler/runtime bridges remain internal.
- Renamed the compiler/runtime bridge ABI to semantic `write_text_raw`, `write_newline_raw`, and `write_char_code_raw` identities so type-suffixed print names do not survive as hidden language builtins.
- Registered typed elaboration roles in Prelude declarations so compiler lowering is symbol-driven rather than module-path-driven.
