# Std 0.2.0-alpha.1 FFI surface

- Added `Ffi.from_c_string` as the public counterpart to `Ffi.to_c_string`.
- Made `Ffi.cfn_from` and `Ffi.cfn_call` preserve complete `Cfn[A..., R]` signatures for zero through sixteen C parameters, and reject unsupported arity, mismatched call arity, or argument types during type checking.
- Kept raw compiler intrinsics private and documented the public `Ffi` pointer, memory, string, and callback APIs instead.
