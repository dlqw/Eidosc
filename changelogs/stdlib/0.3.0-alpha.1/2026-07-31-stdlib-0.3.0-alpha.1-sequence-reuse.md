# Eidos Std 0.3.0-alpha.1 — sequence reuse paths

- Classification: feature
- Latest immutable Std release: `0.1.0-alpha.1`
- Target Std version: `0.3.0-alpha.1`

## Added

- Added `RuntimeArray.take`, backed by a consuming copy-on-write prefix operation.

## Changed

- `Seq.take` now delegates representation and ownership decisions to the runtime-array layer instead of recursively rebuilding the prefix.
- `Seq.append` now uses the consuming runtime-array extension path, allowing the compiler and runtime to reuse uniquely owned storage without changing the source-level `Seq` abstraction.
