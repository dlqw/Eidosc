## 原生链接链路（首次真实链接暴露并修复的五个雷）

1. **rlgl.h 无包含守卫**：`#include rlgl.h` 的 TU 拼进单 shim 编译单元会重定义 glad 全局
  （`GLAD_GL_VERSION_*` 非静态定义在实现段，段本身在头守卫之外）。驱动 `--project` 改为
  **per-TU shim 文件**（`c2e_shims_{n}_{tu}.c` 各含自己的 .c 与访问器），与 C 项目真实构建形态一致；
  跨 TU 同名 accessor/包装按函数名去重（SplitShimBlocks：列 0 起始行为块首，函数名取 '(' 前末标识符）。
2. **`-D` 宏不进 manifest**：shim TU 以 include 原 .c 提供地板实现，编译环境必须与翻译时一致。
  驱动将 `-D` 烤入 `native/c2e_config.h`（shim 头部 include）并发射 `includePaths = ["native"]`。
3. **const 记录拼写**：rshapes 首注册的记录拼写带 `const ` 前缀，accessor setter 转型目标
  变只读。`StripCQualifiers` 在 `CollectRecord` 与 accessor 发射处统一剥离。
4. **函数指针成员 accessor**：`float (*)(float, void*)` 不能作声明符返回类型，改以 `void*`
  中转（cast 位合法；Eidos 侧该成员本就映射 RawPtr）。
5. **内部链接/内联/intrinsic 符号链不上**：static 函数（rprand_xoshiro——定义处无 static
  关键字继承自原型，须按 `clang_getCursorLinkage == Internal` 判定）、头文件内联函数
  （`clang_Cursor_isFunctionInlined`）、MSVC intrinsic（`__cpuid`——系统头+无体+`__` 前缀，
  clang 在 C 侧按内建内联展开、无库符号）一律经 **TU 内转发 shim**
  （`c2e_ext_{tu}_{name}_st`，TU 标签防跨 TU 同名 static 撞符号）暴露；
  转发签名用 canonical 拼写（`__size_t`/`__builtin_va_list` 等内部名展开为 ABI 等价基础类型），
  函数指针形参声明位以 `void*` 中转、调用位 cast 回原签名。

链接配置：`--link-flags "-lopengl32 -lgdi32 -lwinmm -luser32 -lshell32"` 写入
`eidos.toml [ffi] linkerFlags`；跨包消费方以包限定 import（`import raylibfull.Raw`）。

## tier-2 构造

- **static 局部**：标量提升为模块级 mut 绑定（`c2e_static_{fn}_{var}`，初始化经与全局一致的
  强转电池）；数组一律走 **C 侧 static 承载 + getter**（`c2e_static_{tu}_{fn}_{var}_init()`
  返回 `static` 存储地址；非零查表以 token 原文回填初始化器）——模块级初始化不得触
  Ffi/extern（E3003 module-init 效果授权），且 C static 本是稳定存储而非堆缓冲。
  引用经 `EidosRefName` 路由（数组路由到 getter 调用文本，数组不可整体赋值故基址只读成立）。
- **指派初始化器**：libclang 暴露**语法序**——指派项是"目标 + 值"双子包装
  （`DesignatedInitExpr` 或其 UnexposedExpr 形态）；记录按字段名落位、数组按下标落位
  （下标目标的 IntegerLiteral 拼写为空，值在 token 里）；隐式零填充
  （无子 UnexposedExpr）按洞处理（记录补零值/数组 calloc 已零化跳过）。
- **goto/labels**：函数体含顶层标签时切换**分段模式**——`mut c2e_goto := 0; loop { if
  c2e_goto <= i then { 段i } ...; break; }`；`goto L` → 设段号 + continue 包装循环
  （前跳落段、回跳成环、段号 ≤ 门限顺序执行 = C 落穿语义）。顶层局部提升为循环外预声明
  （零值）+ 段内声明改重绑定（跨段词法作用域 + 回跳重入与 C 重新执行声明一致）。
  诚实跳过：goto 跨 C 循环/switch 边界（continue 会绑错目标）、目标为嵌套标签。
  LabelStmt 的子节点是被标记语句——内容必须执行（标签行与语句分离时也如此）。
- **函数指针**：间接调用（空名 callee / 具名 RawPtr 局部）按被调原型生成 **icall shim**
  （`c2e_icall_{签名摘要}`，`void*` 首参转型调用；跨 TU 同签名自动合流）；函数取址
  （`&fn`/函数名值用）经 **addr shim**（`c2e_addr_{tu}_{fn}` 返回 C 函数地址，static/内联
  同样可取）。函数指针形参声明位以 `void*` 中转（cast 位保留真签名）；函数指针**返回**
  经 typedef 中转（名字插进返回类型的 `(*)` 槽位，`void*` 回传——glad loader 的
  GLADloadproc 形态，解锁 81 函数）。诚实跳过：签名含 C float（32 位 ABI）。
- **模块初始化硬边界**（E3003 module-init 效果授权）：源 extern 调用与块表达式内嵌套
  调用都不行；预编译 std 直呼可以。static 标量的 Int→Float 字面量初始化直接拼 `.0`，
  Float→Int 语境诚实跳过；static 数组因此不走模块绑定而走 C 侧 getter。
