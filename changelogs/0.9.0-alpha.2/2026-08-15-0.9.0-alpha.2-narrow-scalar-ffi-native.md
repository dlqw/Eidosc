# Native narrow-scalar FFI coverage and Windows compiler-rt link fix

- Adds end-to-end integration tests proving `extern(c)` signatures with `Int8/Int16/Int32`,
  `UInt32`, and `Float16/Float32` parameters and returns lower to exact-width LLVM declares
  (`i8/i16/i32/float/half`) and round-trip natively (`abs`, `sqrtf`).
- Native links on the Windows MSVC target now include `clang_rt.builtins-<arch>.lib` from the
  clang installation when present; without it, any module importing `std.FloatNarrow` failed to
  link with undefined `__truncdfhf2`/`__extendhfsf2` (half conversions lower to compiler-rt
  libcalls).
- `RunSourceAtLlvm` sets `AllowVirtualInputFile` like the MIR helper, so virtual-input tests
  can import non-prelude-core std modules (`std.IntNarrow`, `std.UInt`, `std.FloatNarrow`);
  previously such imports silently reported `E3000` because module preloading bailed on the
  missing input file.
