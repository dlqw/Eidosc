# Unsigned integer suffix literals

- Add unsigned integer suffix literals `u8`/`u16`/`u32`/`u64` (e.g. `255u8`, `65535u16`, `42u32`, `100u64`), which parse as `UInt8`/`UInt16`/`UInt32`/`UInt64` instead of the default `Int`.
- The lexer now recognizes the multi-character unsigned suffixes and excludes the suffix from the numeric body it hands to the parser (also fixing the previously ignored single-character suffix body).
- `LiteralExpr` carries a `LiteralTypeSuffix`; type inference and the MIR type registry map each suffix to the corresponding unsigned builtin scalar.
- Adds parser regression coverage for all four suffixes.

Known follow-up: explicit `UInt*`/`Int` conversion functions and unsigned division/comparison semantics (separate increments), plus the tutorial BNF and editor-plugin syntax-sync required by the language-surface change.
