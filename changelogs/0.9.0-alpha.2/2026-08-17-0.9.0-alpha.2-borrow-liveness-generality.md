# Borrow liveness ending: generality pass across both analyses

Completes the liveness-gated borrow ending as a general mechanism instead of
the minimal paths that unblocked projects/ecc.

- **All optimizer construction sites** now pass the Ref/MutRef resolver to
  the inliner: the main build, MIR restore, and the query-driven pipeline
  share `MirOptimizer.CreateBorrowTypeResolver` (backed by the HIR type
  descriptor table), so incremental and query compilations inline
  borrow parameters identically to full builds.
- **Dead-borrower pruning covers both borrow analyses.** The classic
  `BorrowChecker` (the second emitter of mutable-conflict diagnostics) now
  ends borrows whose borrower is dead before checking conflicts, matching
  `LoanConstraintVerifier`; the five conflict paths there (mutate-while-
  borrowed, move-of-owned, shared/mutable borrow creation for both the
  target and local forms, plus the `AddBorrow` conflict funnel) all prune.
  The deadness test itself moved to a shared `BorrowLivenessGate`
  (block-local definition-before-use scan + LivenessAnalyzer LiveOut,
  conservative when liveness is absent).
- **The gate treats a borrower consumed by the conflict instruction itself
  as live** (`store %x, %borrower`): an initial version only scanned
  following instructions and suppressed five genuine-conflict anchors
  (move-borrow-handle, call-returning-borrow, out-of-order blocks, alias
  trace linkage, primary/related span propagation); the current-instruction
  use check restores all of them while keeping the ecc shapes clean.
- **Seq discriminator robustness**: the base-type lookup for local bases
  uses a per-function cached local→type map instead of a linear scan;
  nested projections (`grid[i][j]`) and `Ref[Seq]`-deref bases resolve
  through the place TypeIds on the primary path.

## Semantics note: compare-then-reassign is now accepted

`mut cond := x == "hello"; x := "world"` no longer reports E1002: the
comparison temp's shared borrow dies at its last use (the comparison), so
the later rebind is unblocked — the same deadness rule that unblocked ecc,
now applied uniformly. The old behavior was an over-approximation (borrows
lived until explicit consumption), not a safety property: the temp is never
read after the mutation, so no runtime hazard exists.

Tests codifying the old approximation were converted rather than deleted,
and anchors were retrofitted with live borrowers instead of relying on
immortal borrows:

- `borrow/errors/mutable_borrow_conflict.eidos` →
  `borrow/valid/shared_borrow_dead_before_reassign_ok.eidos` (+ inventory
  and `BorrowCheckerTests` updated to assert the new acceptance).
- The two `BorrowPipelineDiagnosticsTests` mutate-conflict cases and
  `EffectBorrowIntegrationTests.EffectDefinitions_WithBorrowConflict` now
  use a genuinely-live shape (`mref y := x; ref z := x; x + y + z`) and
  still assert a single E1002 (with alias-trace notes where relevant).
- The field-sensitive and symbolic-index conservative anchors in
  `BorrowDataflowTests` keep their borrowers alive via the return value,
  preserving the granularity they were designed to pin down.

New lock-in tests: `InlinedRefArgumentInLoop_SurvivesIterationAliasTurnover`
(inlined Ref argument re-bound each loop iteration; the classic checker was
the missing emitter here) and `NestedSeqProjectionAsOwnedArgument`
(`grid[i]` with non-Copy element Seq[Int] into an owned parameter).
