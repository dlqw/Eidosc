# Narrow scalar conversion functions

- Add `std.IntNarrow` (`from_int8/16/32/64`, `to_int8/16/32/64`) and `std.FloatNarrow` (`from_float16/32/64`, `to_float16/32/64`) for explicit conversions between `Int`/`Float` and the narrow signed/float builtins.
- The signed int conversions lower to LLVM `trunc` (narrowing) and `sext` (sign-extend widening); the float conversions lower to `fptrunc` (narrowing) and `fpext` (widening). `Int64`/`Float64` pairs are no-ops.
- Resolves the `E4000` narrow-value-construction gap recorded in the toolchain plan (section 7.2): an `Int` literal can now be passed to an `Int32` FFI parameter via `IntNarrow.from_int32`, and a `Float32` return converted back via `FloatNarrow.to_float32`.
