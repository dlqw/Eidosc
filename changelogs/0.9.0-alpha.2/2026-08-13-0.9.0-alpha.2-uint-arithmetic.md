# Unsigned integer arithmetic and comparison semantics

- Give `UInt8`/`UInt16`/`UInt32`/`UInt64` the builtin `Eq`/`Ord`/`Num`/`Show`/`Clone`/`Hash`/`Copy` trait instances (matching `Int`), so unsigned values support `==`/`!=`, `<`/`<=`/`>`/`>=`, and `+`/`-`/`*`/`/`/`%`.
- Make the LLVM integer lowering signedness-aware: unsigned division lowers to `udiv`, unsigned remainder to `urem`, and unsigned comparisons to `icmp ult/ule/ugt/uge`; signed operands keep `sdiv`/`srem`/`slt`/`sle`/`sgt`/`sge`.
- Adds trait-instance coverage for the four unsigned builtins.

Known follow-up: narrow signed scalar value construction (`Int` -> `Int32` etc., E4000) and module-level mutable global (B2), plus tutorial BNF + editor-plugin syntax-sync.
