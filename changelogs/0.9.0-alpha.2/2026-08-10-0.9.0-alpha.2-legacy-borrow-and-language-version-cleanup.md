# Remove legacy borrow spellings and historical language loading

- Remove the undocumented `&expr` borrow spelling and the `MutRef[T]` builtin alias. Use `ref expr`, `mref expr`, `Ref[T]`, and `MRef[T]`.
- Project loading and compilation now accept only the current Eidos `0.9.0-alpha.1` language version; historical versions remain migration inputs rather than compiler pipeline versions.
- Existing projects that still declare `0.8.0-alpha.1` must migrate their manifest and source before compiling with this toolchain.

This breaking cleanup targets Eidos `0.9.0-alpha.2`; the latest immutable release is `0.9.0-alpha.1`.
