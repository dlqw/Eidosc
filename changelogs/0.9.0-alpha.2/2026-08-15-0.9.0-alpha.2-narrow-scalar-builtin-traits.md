# Narrow int and float scalars implement the builtin traits

- `Int64/Int32/Int16/Int8` now report `Eq/Ord/Num/Show/Clone/Hash/Copy` and
  `Float64/Float32/Float16` report `Eq/Ord/Num/Show/Clone/Copy`, matching the existing `Int`,
  `Float`, and `UInt` rows in `BuiltinTraits`.
- Values returned from `extern(c)` narrow-scalar signatures can now use operators and
  comparisons directly instead of widening through `std.IntNarrow`/`std.FloatNarrow` first.
