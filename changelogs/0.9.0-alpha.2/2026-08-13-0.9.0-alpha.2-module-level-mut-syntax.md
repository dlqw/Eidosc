# Module-level mutable binding syntax (parse + semantic stage)

- Accept `mut name := expr;` at module top level (name-first syntax), parsed as a mutable `LetDecl` and registered as a module-level mutable variable (`VarSymbol.IsModuleLevel` + `IsMutable`). This is stage 1 of the module-level mutable global work item (plan `eidos-module-level-mutable-globals-design-2026-08-13`): the syntax and naming are accepted; MIR lowering is not yet implemented and reports `E5001` (clear diagnostic, not an internal error).
- Adds parser coverage for the top-level `mut` binding form.

Known follow-up: HIR/MIR module-variable storage and LLVM global lowering (stages 2/3 of the design plan).
