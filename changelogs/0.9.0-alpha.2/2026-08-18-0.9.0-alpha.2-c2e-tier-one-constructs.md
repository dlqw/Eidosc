# C2E: tier-one construct coverage (switch, loops, casts, member paths, sret)

Lands the full raylib-class backlog (handover §3 #4-#10 minus the &local
design item). The new comprehensive gate `C2E_TierOneConstructs_ParityWithClang`
exercises every feature below against a clang-compiled reference (exit codes).

## Control flow

- **switch** desugars to a wrapper loop over per-segment conditionals with a
  match latch. Entry semantics are segment-level: a run split at each new case
  label, so entering at a later label executes only that label's statements
  and onward (fallthrough); mid-run conditional `break` exits the wrapper;
  break-closed runs reset the latch. Nested empty labels (`case 2: case 3:`)
  arrive as nested CaseStmt children and accumulate recursively. Case values
  fold via clang constant evaluation; the selector is evaluated once into a
  local (C semantics). `continue` inside a switch body maps to `break`
  (exits the wrapper; the enclosing loop then proceeds normally — code after
  the switch in the loop body is the documented approximation).
- **C `break`/`continue` translate** (were never supported: kinds 213/212).
  `for` and `do-while` use rotated desugars (increment/condition hoisted to
  loop top behind a first-iteration flag) so C `continue` maps directly to
  Eidos `continue` at the loop top; `while` keeps the guard-top form.
- **for slot classification**: empty slots emit no libclang children, so
  DeclStmt/assignment/comma before the condition pin as init and everything
  after as increment (`for (i = 0, j = n; i < j; i++, j--)`, `for (;;)`,
  `for (; k < 3;)`). Comma sequences flatten in statement position.
- **Condition-position assignment** (`while ((x = f()))`, `if ((x = f()))`)
  hoists the assignment to a statement (inside the loop before the guard for
  loops) and conditions on the target. Integer-valued conditions normalize to
  `!= 0` with a shape-based Bool test — the clang type of a C comparison is
  `int` while its translation is Eidos `Bool`, so type-based normalization
  double-wrapped comparisons (also fixed in the ternary path).
- **do-while** desugars (rotated).

## Expressions and types

- **Character literals** evaluate as integer constants (kind 110).
- **`(int)double`** truncates via new `Ffi.trunc_to_int` (fptosi) and
  **`(long)ptr`** via `Ffi.ptr_as_int` (ptrtoint) — new intrinsics
  `float_to_int`/`ptr_to_int` with codegen entries, exported from std.Ffi.
- **`(void)x`** discards to a Unit block; statement-position casts to Unit and
  bare reference statements (kind 101) and empty statements (kind 230, empty
  macro expansions) drop to `()`.
- **Parameter mutation**: C mutates parameters freely; on the first
  "mutation of parameter" failure the translator registers the parameter and
  retries the body, emitting `mut name := name;` shadow copies at the top.
- **2D array locals** (`T a[N][M]`) map to flat RawPtr buffers; nested
  subscripts compose through array decay.

## Member paths

- Member access re-types from the base expression's own clang type (cast
  bases like `((T*)q)->f` no longer resolve through the declared variable
  type; cast cursors are preserved as path heads).
- **Pointer-rooted member paths** (`p->a.b`, `pts[i].x.y`, `((T*)q)->m`):
  intermediate struct members advance through new `c2e_<R>_<m>_addr` shims
  and the final scalar member uses accessor get/set on the innermost
  address. This replaces value-chaining through `c2e_<R>_<m>_get`, which
  would have declared externs returning structs — no ABI bridge exists
  (E3051); struct-typed members now emit only `_addr` accessors.
- **Value-rooted nested writes** (`o.in.b = v`) rebuild the whole record
  (`Outer { in: Inner { a: o.in.a, b: v }, tag: o.tag }`) instead of nested
  `.{}` updates on projected bases — the shorthand requires a stable base
  place (E4000).
- **`&p->m` / `&p->a.b`** compute member addresses through the same chain
  (`c2e_<R>_<m>_addr`).
- **sret shims**: extern functions returning structs by value now translate —
  a C shim with a static slot returns `&slot` (bindgen M4 precedent, not
  thread-safe) and the call site reassembles the Eidos record through field
  accessors inside a block expression. Float parameters narrow in the shim.
  By-value struct *parameters* remain guarded off.

## Shim emission

The accessor/float/sret shim sections share a single `#include` of the input
file (it has no include guard; two sections doubled it into a redefinition),
and accessor C signatures use the clang type spelling rather than the Eidos
type name.
