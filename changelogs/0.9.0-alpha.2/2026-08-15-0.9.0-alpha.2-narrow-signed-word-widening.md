# Sign-extend narrow signed integers when widening to the i64 word

- Integer arithmetic (`Add/Sub/Mul/Div/Mod`) and mixed-width ordered comparisons previously
  widened narrow operands with `zext`; for negative `Int8/16/32` values this produced wrong
  `sdiv`/`srem` results and wrong ordered comparisons (for example `Int32 -7 / 2` returned
  `2147483644` instead of `-3`).
- Widening now selects `sext` for signed narrow operands and keeps `zext` for unsigned and
  pointer-derived values; `Add/Sub/Mul` results are unchanged (modular arithmetic composes
  with either extension).
- Adds a native regression test (`NarrowScalar_Int32SignedDivision_NegativeOperands_TruncateTowardZero`)
  that fails on the previous zero-extending lowering.
