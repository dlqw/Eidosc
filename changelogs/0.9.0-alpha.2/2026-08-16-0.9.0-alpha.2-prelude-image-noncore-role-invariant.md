# Exclude opt-in module roles from the prelude image invariant

- `CompilationPipeline_CoreImage_RegistersEveryTypedElaborationRoleExactlyOnce` asserted
  every `CompilerSemanticRole` registers exactly one function when compiling an empty
  program. `SequenceBuilderFreeze` (added with the sequence builder fusion work) is
  hosted by `std.SeqBuilder`, which is not part of the implicit prelude core image, so
  the role only registers when user code imports that module and the test failed.
- The test now filters roles hosted by opt-in modules through an explicit, documented
  `RolesOutsideCoreImage` set instead of failing.
