# Bind narrow C scalars directly without narrowing shims

- `pkg bind` maps C `char/short/int` (and the explicit `int8_t..uint32_t` spellings) to Eidos
  `Int8/16/32`/`UInt8/16/32`, `float` to `Float32`, and unsigned 64-bit integers to `UInt64`;
  signed 64-bit keeps the idiomatic `Int`. `char` sign follows the extractor's `IsUnsigned`
  flag, and `long`/`unsigned long` follow the recorded layout size (LLP64 vs LP64).
- Narrow-scalar parameters and returns now cross the FFI boundary at native widths
  (E5337 closed), so `BindingCShimGenerator` no longer widens them to `int64_t`/`double`:
  the narrowing shim remains only for enums and layout-less leftovers. Struct-by-value split
  shims keep native-width leaf parameters, keeping the generated Eidos signature and the shim
  C signature one-to-one.
- Raylib gate (real `raylib.h`, clang mode): 931 bindings with 2741 narrow-type positions
  bound directly; the remaining auto shim consists solely of struct-by-value assembly, and
  the generated module still passes the full semantic pipeline through the LLVM phase.
