# Functional Std composition

- Reworked derived Prelude and Std implementations to compose existing functional primitives through pipelines and fluent calls instead of nested prefix calls.
- Routed `Seq.sum` and `Seq.product` through `fold_left`; specialization now lowers the direct reducer to a source-index loop and exact-arity inlining removes the curried closure protocol and its aggregate round-trip.
- Added proof-driven multi-parameter direct-call inlining and copy-only aggregate scalarization; partial applications, indirect closures, borrowed values, and non-copy accumulators retain their original boundaries.
- Added regression coverage that confines mutable control flow to the explicit container/data-structure kernels and prevents derived sequence transforms from returning to prefix-call style.

This is a source-clarity and performance fix with no public API or semantic change. A 25-sample native benchmark over 125 million reductions measured `Seq.sum` at 566.26 ms median versus 571.74 ms for the hand-written loop; all runs returned checksum 87.
