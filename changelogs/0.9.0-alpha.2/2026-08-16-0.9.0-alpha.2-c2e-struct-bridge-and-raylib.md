# C2E: struct-by-value record bridge, globals, and extern floor fallback

Body translator extensions, validated by translating the real raylib sources
(`refs/raylib/src/rcore.c` + `rshapes.c`, Win32 + OpenGL 3.3 config) into Eidos:

- Struct-by-value bridge: TU-level struct/union declarations map to Eidos
  named-field records (`Color :: type { r :: Int, ... }`); by-value params,
  returns, and locals translate; `s.f` reads and `s.f = v` writes on value
  records become `s.f` / `s := s.{f: v}`; positional init lists and compound
  literals `(Vector2){ x, y }` become record constructions with C zero-fill.
- File-scope globals of mappable type map to module-level `mut` bindings
  (raylib's `texShapes`/`texShapesRec` initialize from their real C values).
- ParenExpr now preserves C grouping in the emitted text (previously dropped,
  which silently changed `(a + b) * c` into `a + b * c`); the C usual
  arithmetic conversions are covered for Int/Float mixes at binary operators,
  assignments, returns, and call sites (Int→Float via a generated
  `c2e_int_to_float_shim`); compound assignment statements desugar to
  rebinding; Unexposed statement/callee wrappers unwrap transparently.
- C `float` (32-bit) externs route through generated double↔float ABI shims
  (`c2e_ext_<name>_f`) so Eidos `Float` (f64) cannot mismatch the C ABI;
  extern `PendingExtern` now binds the shim symbol.
- Calls to same-file functions that fail translation (or are filtered out via
  the new `Translate(cSourcePath, includePaths, defines, onlyFunctions)`
  overload) fall back to `extern(c)` against the floor-compiled C symbol
  instead of poisoning callers; indirect (function-pointer) calls are skipped
  with a dedicated reason and no longer pollute the banned set; the fixpoint
  retry keeps the skipped-function list stable across rounds.
- Statement-level ParenExpr/UnexposedStmt/CStyleCast wrappers, `++`/`--`
  statements, and ternary conditionals now translate (ternary maps to the
  Eidos if-expression with Int-condition normalization and arm promotion).
- `ClangNative` gained `clang_EvalResult_getAsDouble` (float literals no
  longer go through the undefined `getAsStr` path).

Measured on real raylib sources: rcore 180→628, rshapes 8→64, rtext 92→197,
rtextures 225→341 functions translated. The snake-gui-c2e demo project
(projects/snake-gui-c2e) consumes the `raylib-c2e` package with a byte-identical
copy of snake-gui's game logic; headless benchmark checksums match the bindgen
build, and the GUI runs with drawing driven by the translated layer.
