# Preserve CopyLikeTypeIds when optimization passes rebuild the module

- `MirOptimizationCloner.WithFunctions` (backing `DecisionSimplification`,
  `ConditionalValueSelection`, `CommonSubexpressionElimination` and
  `LoopInvariantCodeMotion`) dropped `CopyLikeTypeIds` when cloning the module, so the
  first decision-core pass emptied the set for the rest of the pipeline.
- `TypeLowering.RecomputeInlineValueRecordTypes` then classified no records as inline
  values, and `derive(Copy)` records such as `Point` lost the first-class
  `%struct.eidos_Point` by-value ABI at call boundaries (issue #76).
- The cloner now copies the set; `SmallCopyRecord_UsesInlineValueAbiAcrossCallsAndNativeExecution`
  and `Create_RestoredSmallCopyRecord_PreservesInlineLlvmValueAbi` pass again.
