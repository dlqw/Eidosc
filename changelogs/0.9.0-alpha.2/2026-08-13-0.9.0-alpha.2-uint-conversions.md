# Unsigned integer conversion functions

- Add the `std.UInt` module with explicit `Int` ↔ `UInt8`/`UInt16`/`UInt32`/`UInt64` conversions: `UInt.from_int8/16/32/64` and `UInt.to_int8/16/32/64`.
- The conversions are compiler intrinsics (`uint<N>_from_int` / `uint<N>_to_int`) lowered to LLVM integer casts: `trunc` for narrowing, `zext` (zero-extend) for widening, and no-op for the `UInt64` ↔ `Int` pair.
- Adds intrinsic-registry coverage for the new conversion names.

Known follow-up: unsigned division/comparison semantics (separate increment) and the tutorial BNF + editor-plugin syntax-sync for the unsigned suffix literals already merged in #67.
