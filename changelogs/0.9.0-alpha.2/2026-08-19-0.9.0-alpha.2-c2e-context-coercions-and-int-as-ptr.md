# C2E: context coercions, pointer arithmetic, struct staging; raylib 4-TU gate passes the full LLVM backend

Drives the raylib 4-TU merged module from 105 type-level gate errors to a
**full-backend (phase Llvm, 0 errors) pass over 654 translated functions**,
and fixes a language-layer literal bug the gate exposed.

## Language: `l`-suffixed literals silently became String

`LiteralExpr.ParseLiteral` only stripped the `u8..u64` suffixes; the lexer's
Int64 suffix `l` (mandatory for values above Int32, which the lexer otherwise
rejects with ErrInvNumber) was left attached, so `long.TryParse` failed and
the literal fell through to `LiteralKind.String`. Every C2E emission of a
>i32 constant (`3993919788l`) therefore had type String — 37 of the 105 gate
errors. ParseLiteral now strips a trailing `l` before parsing, and the
hex/binary/octal branches gained Int64 fallbacks (previously out-of-range
hex silently became `0`).

## Translator: pointer arithmetic and pointer literals

- `p + n`, `n + p`, `p - n` → `Ffi.offset_bytes(p)(n)`; pointer difference
  `p1 - p2` → `Ffi.ptr_as_int` difference divided by the pointee element size
  (C element-count semantics). Compound forms (`p += n`, `p++`, for-increment)
  step by the pointee size; `for (;; p += n)` routes compound assigns through
  the shared statement desugar instead of dying on cursor kind 115.
- NULL handling generalized: `IsPointerLiteral` no longer requires the literal
  itself to be pointer-typed (C `p != 0` passes an int-typed 0) and unwraps
  `ParenExpr` (NULL macros arrive as `((void*)0)`). All flow positions coerce
  through one helper: var-decl init, plain/member/subscript assignment, return,
  call arguments, conditional arms, and file-scope globals.
- New intrinsic `int_to_ptr` (inttoptr) with `Ffi.int_as_ptr` wrapper:
  non-null integer-as-pointer casts — the Win32 `MAKEINTRESOURCE` shape
  `(char*)32512` in `GetCursorName`, and `(T*)(size_t)x` macro chains — now
  round-trip instead of leaking an Int into a RawPtr context.
- Pointer comparisons extended to ordering (`encode < end_output` buffer
  sentinels) via `ptr_as_int`; pointer truthiness (`if (p)`) normalizes to a
  `pointer_eq` null check in conditions and `&&`/`||` operands.

## Translator: Bool/Float/String coercions at every consumption point

- C comparisons are int 0/1: operands of arithmetic/bitwise operators are
  digitized (`(if c then 1 else 0)`); `bool == 0` rewrites to negation; `!x`
  on Bool-shaped operands is a direct negation instead of Int `x == 0`;
  comparator ternaries (`c ? -1 : (a < b)`) digitize the Bool arm.
- `NormalizeConditionText` wraps the whole condition before appending
  `!= 0` — `flags & FLAG` used to become `flags & (FLAG != 0)` since Eidos,
  like C, binds `!=` tighter than `&`.
- Float coercions completed: compound assignments (`a *= 2` with float `a`)
  lift the Int side; Float→Int consumption points truncate via
  `Ffi.trunc_to_int` (fptosi).
- String literals as subscript bases (`"OTTO"[0]` tag comparisons) wrap in
  `Ffi.to_c_string`.

## Translator: struct-by-value arguments cross the ABI by staging

`UnloadImage(glyphs[i].image)` / `ImageTextEx(font, …, color)`-shaped calls
previously skipped (no extern ABI for struct params). Both extern paths —
plain and sret — now emit a C wrapper shim (`c2e_ext_<name>_v` /
`_sret`) that takes pointers and dereferences at the call, while the Eidos
side stages each struct argument into a `Ffi.calloc` slot through per-field
accessors (nested record fields recurse via member `_addr` chains, the same
shims the sret return uses). Record-typed members read in value position
(`glyphs[i].image`) reassemble from the member `_addr` slot the same way.

## Translator: effect and emission correctness

- `need ffi` marking no longer depends on PendingExterns/FloatShims dict
  deltas (`TryAdd` doesn't grow for repeat externs — every caller after the
  first missed the mark, 36×E3003 at the Effects phase): extern call
  resolution marks the current function directly, and the `(float)x` cast
  path now ticks the ffi counter too.
- Translated records are emitted `@[derive(Copy)]`: C structs are value
  semantics, and without Copy every by-value pass moved the record
  (`color, color, color` → E1001 at the Borrow phase). This single line
  cleared the entire 104-error borrow class.
- Member-accessor registration merges `NeedsAddress` instead of
  overwriting — a later sret-reassembly registration used to erase an
  earlier `&p->m` address need, dropping the `_addr` shim from emission.
- File-scope global initializers are translated before enum-constant
  bindings are emitted (`logTypeLevel = LOG_INFO` registered its enum
  reference after that section had already run).
- C `{ 0 }` record initializers zero-fill non-scalar fields; `*a[i]` /
  `*(a + 3)` dereferences unwrap implicit casts and accept any
  pointer-typed operand.
- Honest skips: C variadic internal calls (`stbiw__outfile`'s fmt-driven
  va_list) and function names used as values (glad loader callbacks).

## Tooling

- c2e driver `--compile-file` renders full diagnostics (snippet + caret)
  for any Eidos file through the gate pipeline — the line-only gate output
  couldn't disambiguate sites on the 22k-line merged module.
- Project-mode block merge dedups extern accessor blocks per `@[extern]`
  declaration pair: get/set/addr ship in one block whose header is identical
  across TUs, so whole-block first-wins dropped the `_addr` declarations only
  the last TU had registered.
