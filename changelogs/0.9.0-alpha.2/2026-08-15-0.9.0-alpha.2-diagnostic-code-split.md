# Split module-variable and function-signature diagnostics off E5301/E5302

- Module-level mutable initializer diagnostics now report `E5312` (MIR compile-time literal gate)
  and `E5313` (LLVM static-scalar gate) instead of reusing the generic-specialization codes
  `E5301`/`E5302`, which keep their original meanings.
- Unresolved function-signature types during LLVM lowering now report `E5314` instead of `E5302`,
  removing the last double use of that code.
- `E5313` gains a regression test covering the string-initializer fallback to a zero-initialized
  global (previously untested).
