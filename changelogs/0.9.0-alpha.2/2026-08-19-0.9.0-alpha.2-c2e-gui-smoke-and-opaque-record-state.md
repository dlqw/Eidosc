## 原生链接/运行
- 冒烟项目新增 `gui_smoke`（与 `ref/gui_ref.c` 同一调用序列）：InitWindow →
  IsWindowReady/GetScreenWidth/GetScreenHeight → 三帧 BeginDrawing/ClearBackground/
  DrawPixel/EndDrawing → GetTime/GetWindowPosition → CloseWindow → IsWindowReady。
  GL 全初始化（VAO/着色器/默认字体），退出码 0。
- **关键修复——C/Eidos 全局状态分裂**：shim TU `#include` 原 .c，其内原 C 定义（`CORE`、
  `defaultFont`、`shapesTexture`、静态查找表）与 Eidos 模块绑定并行存在，直译各写各的
  导致崩溃（`.recs[95]` 空指针）。
  - 不透明 record/数组全局：getter 改为 `extern <type> name; return &name;`
    （static 定义在 TU 内直接 `&name`）——与 C 侧共享同一份存储，废弃私有副本方案。
  - 可映射值记录全局族（`defaultFont`、`shapesTexture`）：引用它们的函数**保持 C 侧**
    （banned → 调用方回退 extern；值记录返回经 sret），杜绝两态分裂。
- 链接：`_alloca`（MSVC 单下划线 intrinsic，如 `SetWindowTitle`）纳入转发类
  （clang 在 C 调用点内联）。多维数组/函数指针元素的全局 extern 声明位拆分基类型+维数。

## 翻译率（880 → 599 skip；1019 函数 / 104 floor）
- **不透明 record 存储**（不可映射 struct：含数组/嵌套/匿名成员）：局部 `Ffi.calloc`,
  static 提升复用 StaticInitShim（Count=1），全局 C 共享 getter；成员经 accessor 链访问。
- **匿名嵌套 struct（raylib CoreData 形态）**：成员链改为**路径摊平 accessor**
  （`c2e_CoreData_Window_screen_width_get`，C 侧 `->Window.screen.width`），游标链
  （clang_getTypeDeclaration，新导出）逐级验证，绕开"匿名记录无以命名"。
- **osret**：返回不可映射 record 的调用 + 结果成员访问（`rlMatrixToFloatV(mat).v`）——
  C 侧 malloc 槽收返回值（逐调用槽防嵌套互踩，泄漏换正确性）；值记录参数 staging。
- **盒化值记录局部**：`&msg`（PeekMessageW 输出参数）→ 升级 calloc 存储盒整体重译；
  按值使用位（return/实参）从盒地址重组记录值。
- **变参调用**（TraceLog/TextFormat 型）：按调用点实参固化的 C 转发 shim；变参位按
  C 默认实参提升（float→double、小子整型→int）。
- record 元素下标读/写（`GetFontDefault().recs[95]`）：地址上逐字段重组/装载；
  值记录成员写（`CORE.Window.screenScale = MatrixIdentity()`）经 _addr 槽逐字段装载。
- 整型字面量在 float 语境（`DrawCircleSector(..., 0, 360, ...)`）按本源 Int 判型矫正。
- accessor 调用方 need ffi 直接标记（计数差只覆盖首次登记，后续调用方漏标 E3003）。
- 剩余大头：158 个语句 kind 215 = **GCCAsmStmt**（stbir SSE 内联汇编，诚实跳过）。
