# Open module namespaces

- Unaliased module imports now expose accessible public types and effects as bare names alongside existing values, constructors, and trait methods.
- Aliased module imports remain qualified, preserving an explicit boundary for namespace ownership and conflict resolution.
- Added regression coverage for bare type/effect imports and grouped functional calls used by `map`, `bind`, and `filter` pipelines.

This compatible language enhancement targets Eidos `0.9.0-alpha.2`; the latest immutable release is `0.9.0-alpha.1`.
