# Sequence optimization facts

- 为 `Seq.head` 注册结构化 `sequence.head` compiler role，并在泛型专用化后保留该 role。
- 新增保守的 `SequenceOptimizationFacts`，统一统计 MIR local 的读取次数与 return、未知调用、aggregate store 逃逸。
- 现有 map/filter/fold fusion 通过 single-use + non-escaping facts 检查中间值；证明不足时继续使用原始 eager lowering。
- 在同一 proof gate 下将 `filter |> head` 归一化为 canonical `Seq.find` role call，为后续直接短路单循环 lowering 提供统一入口。
- `SequenceOptimizationFacts` 的 projection store 现在只计算地址依赖，local store target 不再被误计为读取；新增 local/projection store 覆盖测试。
- 收紧 callback inline fallback：effect、panic、divergence、suspend/block、allocation、同步、未知内存或非确定性任一事实存在时，`filter |> head` 保留 eager lowering。
- `Seq.find`、`Seq.any`、`Seq.all` 命中/失败后立即 `break`，不再执行剩余元素访问或无意义的循环尾更新。
- facts 现在额外记录 `MirCopy` alias、`MirLoad.CreatesBorrowAlias` 和显式 borrowed-call 参数；任何 alias/borrow 未被后续 borrow phase 证明结束时，sequence single-use gate 安全回退。
- 新增 `take(xs, positive-constant) |> head` 的 proof-gated 消除；动态、零值、负值或多用 source 均保留原 lowering，并记录 `sequence.pipeline.take_head` 指标。
- 新增 `take(take(xs, a), b)` 的正常量归一化为单次 `take(xs, min(a,b))`；任一边界非正或动态时回退，并记录 `sequence.pipeline.take_take`。
- 新增 `drop(drop(xs, a), b)` 的正整数常量归一化为单次 `drop(xs, a+b)`；整数溢出、非正/动态边界或多用时回退，并记录 `sequence.pipeline.drop_drop`。
- `RuntimeArrayRangeSpecializationPass` 开始消费 alias/borrow facts；slice source 出现共享副本或活动借用时不再生成 range variant。
- 将 sequence fusion 的计划记录、metrics、discovery helpers 和 lowering helpers 拆分为独立源码文件；核心协调文件降至 2000 行以内，行为保持不变。
