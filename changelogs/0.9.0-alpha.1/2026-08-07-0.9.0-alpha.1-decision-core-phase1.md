# Decision core phase 1

- Sync ID: `eidos-decision-core-0.9`
- Classification: none
- Latest immutable Eidos core release: `0.8.0-alpha.1`
- Target Eidos core version: `0.9.0-alpha.1`

## Changed

- The MIR optimizer now consumes block-local constant and copy facts at proven `if`/`match` decision points. A known branch becomes a direct jump; a known unmatched decision uses its default target or becomes unreachable.
- Unknown discriminants and pattern branches that bind values remain unchanged, preserving effect order and binding semantics.

## Performance

- The new pass removes the decision terminator from proven paths and exposes the resulting dead blocks to the existing dead-code elimination pass. No user syntax, optimizer hint, container choice, or manual branch strategy is required.

## Migration

- No source migration is required. This is an internal MIR optimization with conservative proof gates.
