## Arbitrary-width integers and `CString` (feature)

- Add arbitrary-width integer types `I<N>` / `U<N>` (1–4096 bits), with literal suffixes such as `1u8`, `42i24`, `7u512`, and generic `I` / `U` for prelude integer families.
- Unify `Bool` with `I1` / `U1` and preserve `I1` / `U1` in the type system while lowering to LLVM `i1`.
- Add `BigInteger`-backed compile-time evaluation and MIR constants for integer literals beyond 64 bits, and lower them to native LLVM integer constants of the requested width.
- Add FFI-safe `std.CString` with `from_string`, `to_string`, and `as_ptr` wrappers around the runtime C-string representation.
- Remove legacy `l` / `L` numeric suffixes and emit `i64`-suffixed literals in C2E translation.
