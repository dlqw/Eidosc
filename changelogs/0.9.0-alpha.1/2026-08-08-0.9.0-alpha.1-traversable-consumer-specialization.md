# Traversable 消费者驱动专用化

- 为 `Traversable.sequence` 增加消费者驱动的 MIR 专用化：当调用点证明 callback 是编译器自有的 `identity_applicative` 时，克隆具体 `traverse` 实现并将间接 callback 调用消除为值移动。
- proof 同时追踪 callback 的局部 move/copy、闭包环境槽位、环境根别名、单定义约束和 CFG 支配关系；无法证明、闭包快照早于 callback 写入或 callback 已逃逸时保留原实现。
- 保留原 `traverse` ABI 和未知 callback fallback，并输出消费者扫描、identity 命中、克隆数、callback 调用消除数及 fallback 原因指标。

本变更不增加用户可见 API、容器选择或优化提示；`sequence` 的函数式写法保持不变。
