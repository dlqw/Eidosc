# Functional sequence pipeline fusion

- Classification: feature
- Latest immutable Eidosc release: `0.5.0-alpha.1`
- Unified Eidos target: `0.9.0-alpha.1`

## Changed

- Fuse proven `Functor.fmap` to `Foldable.fold_left` sequence pipelines into one source loop without requiring concrete `Seq` spelling, a builder, or a capacity hint.
- Eliminate the eager mapped `Seq` when mapper and reducer reordering, single-consumer ownership, and `Copy` element/accumulator proofs all hold.
- Preserve the original eager pipeline whenever a callback, ownership, shape, or use proof is missing.
- Add per-shape fusion counters and emitted-source-loop profiling so functional spellings can be measured independently.
- Add a required cross-platform proof/native-equivalence CI shard for sequence fusion.

## Verification

- MIR shape and profiling assertions cover functional trait spelling, direct fold lowering, map/filter/fold, map/filter/collect, and conservative fallbacks.
- Native checksum tests cover fused functional map/fold and existing map/filter pipelines.
