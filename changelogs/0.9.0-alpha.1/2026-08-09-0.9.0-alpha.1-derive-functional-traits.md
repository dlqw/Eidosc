## Functional ADT derives

- `@[derive(Functor)]`, `@[derive(Foldable)]`, and `@[derive(Traversable)]` now generate structural implementations for algebraic data types.
- Derivation treats the final ordinary type parameter as the mapping slot, preserves fixed prefixes, recursively follows covariant final arguments, and emits constructor-field diagnostics for unsupported shapes.
- Generated `Traversable` methods preserve effect rows and Applicative evidence; recursive closed-case constructor expressions are promoted to their root ADT when required by the expected result type.
- MIR now preserves the specialized source signature across erased function-value injections, so aggregate arguments use the correct LLVM ABI at indirect closure calls; native regression coverage includes two- and three-field traversals.
