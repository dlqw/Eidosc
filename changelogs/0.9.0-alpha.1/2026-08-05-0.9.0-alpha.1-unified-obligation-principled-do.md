# Unified obligation evidence and principled `do`

- Sync ID: `eidos-functional-obligation-do-0.9`
- Classification: feature
- Latest immutable Eidos core release: `0.8.0-alpha.1`
- Target Eidos core version: `0.9.0-alpha.1`

## Added

- Added a canonical, tabled obligation solver for equality, trait implementation, kind, effect-row inclusion, associated projection normalization, and conjunction goals.
- Added structured evidence, explanation state, cycle/depth/budget protection, and profiling counters for root goals, table reuse, Prelude resolution, and candidate checks.
- Added typed `DoElaborationPlan` records containing constructor identity, SymbolId dependency edges, effect/ownership/refutability proof facts, selected evidence, lowering strategy, and deterministic fallback reasons.
- Added principled `Alternative.empty` failure semantics for refutable `do` bind patterns.

## Changed

- Independent adjacent `do` binds now lower automatically through left-to-right `fmap + apply + bind(identity)` when the Monad, Functor, Applicative, effect, ownership, and pattern proof gates all hold. Dependent or unproven segments retain sequential Monad lowering.
- Concrete Prelude evidence now reaches HIR/MIR as stable callable identity and specializes to direct dispatch without runtime dictionary objects.
- Non-escaping generated continuations participate in stack closure promotion; Option, Result, and Seq lowering is covered through HIR, LLVM, and native execution tests.
- Prelude instance discovery now uses a parser-validated trait-to-provider index and caches closed-type resolution by complete nominal/type/const/effect identity within one solver epoch. Open types are never cached.
- Precompiled module exports are analyzed lazily for the requested module and its re-export dependencies instead of parsing the complete Std surface on the first obligation.

## Performance

- ColdStart absolute results over 8 launches: Basic 925.0 ms / 46.69 MB, Prelude 990.7 ms / 57.47 MB, and Snake GUI 1266.2 ms / 121.14 MB managed allocation.
- Ten alternating independent-CLR Prelude pairs measured 2942.22 ms on the baseline and 2947.48 ms on this branch: +5.25 ms / +0.18%. Medians were 2950.97 ms and 2939.02 ms respectively.
- Lazy export analysis removed approximately 37.95 MiB of first-use allocation observed in the former eager path; the profiled Types phase returned from approximately 386.74 ms / 47.48 MiB toward the 99.65 ms / 9.53 MiB baseline shape.

## Migration

- `do` syntax is unchanged. A refutable bind that previously had no defined failure contract now requires coherent `Alternative` evidence; match failure returns `empty` instead of relying on a partial match or backend behavior.
- No general-purpose `for` syntax, optimizer hint, capacity parameter, builder choice, or dedicated container is introduced.
