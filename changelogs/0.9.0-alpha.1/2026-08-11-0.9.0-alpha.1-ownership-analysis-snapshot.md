# 0.9.0-alpha.1

## Compiler

- 新增编译器内部 `OwnershipAnalysisSnapshot`，统一保存 MIR place provenance、alias、borrow region、must-owned/must-unique、last ownership use、drop、loop-carried、escape、partial move/reinitialize 与退出清理事实。
- Borrow phase 将 snapshot 挂载到 `BorrowCheckResult`，并保留 Liveness、BorrowChecker、LoanConstraintVerifier、Perceus、Reuse 与 SequenceOptimizationFacts 的共同分析上下文。
- 非 debug 构建也保留 borrow point states，确保后续 sequence/view/reuse proof 不会因为缺少 region 信息而错误复用。
