# MIR constant copy propagation

- Classification: fix
- Latest immutable Eidosc release: `0.5.0-alpha.1`
- Unified Eidos target: `0.9.0-alpha.1`

## Fixed

- Propagate known scalar constants through top-level `MirCopy` instructions during MIR constant folding, so pure calls separated by compiler-introduced copies can continue folding.
- Preserve conservative invalidation when a copy source is not a tracked constant.

## Verification

- Added regression coverage for copy-separated nested pure calls, repeated memoized calls, recursive cycles, and empty CFG loops.
