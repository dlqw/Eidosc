# Shared optimizer proof index and snapshot lifetime

- Classification: perf
- Latest immutable Eidosc release: `0.5.0-alpha.1`
- Target Eidosc version: `0.5.0-alpha.2`

## Changed

- Unified constant-call folding, common-subexpression elimination, loop-invariant motion, dead-call elimination, MIR inlining, and linear-recurrence authorization behind one conservative function-capability proof model.
- Shared the function identity index and recursive-call analysis between effect summaries and structural recursion checks instead of rebuilding them independently.
- Reused proof indexes across consecutive optimization passes while the MIR module snapshot is unchanged, and invalidated them whenever a pass produces a new snapshot.
- Released pass-owned proof references immediately after each pass and retained only compact recursive function keys, preventing the complete recursive component graph from extending the optimizer's peak live set.
- Added a dedicated `proofs.analyze` detailed-profile subphase for allocation and timing regression gates.

## Verification

- Added tests for semantic versus structural recursion proof boundaries, same-snapshot proof reuse, and proof invalidation after MIR changes.
- Preserved the existing effect-aware folding, elimination, reuse, inlining, and recurrence regression suites.
- On ten alternating isolated-process Snake Native samples, reduced optimizer allocation by about 4.0% and optimizer time by 1.3% at the median (4.4% by the mean), while peak working-set and private-memory medians stayed within 0.1% of the `0.5.0-alpha.1` baseline.
