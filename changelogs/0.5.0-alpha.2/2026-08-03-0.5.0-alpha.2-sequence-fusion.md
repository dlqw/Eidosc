# Proof-driven eager sequence fusion

- Classification: perf
- Latest immutable Eidosc release: `0.5.0-alpha.1`
- Target Eidosc version: `0.5.0-alpha.2`

## Changed

- Added compiler-owned semantic roles for canonical `Seq` stages and preserved them through generic specialization, MIR payloads, fingerprints, and convergence checks.
- Added a strict sequence-callback reorder capability requiring trusted pure effects, no observable memory access, panic, divergence, suspension, blocking, allocation, synchronization, or nondeterminism.
- Added the first `SequencePipelineFusionPass` vertical slice for direct `map` → `filter` → `fold_left` pipelines over proven `Copy` elements and accumulators.
- Rewrites accepted pipelines to one source loop, eliminates both eager intermediate sequences, and preserves `Ref[T]` predicate ABI semantics.
- Keeps effectful, panic-capable, divergent, unknown-closure, multi-use, unsupported-shape, and unproven-ownership pipelines on the original safe path.
- Exposes pipeline formation and fallback-reason counters through detailed profiling and MIR debug summaries.
- Made `profile-batch` averaging of `long` allocation and counter values overflow-safe.

## Verification

- Added MIR-shape, native checksum, callback-proof, role registry, fingerprint, payload, profiling-counter, and extreme-counter averaging tests.
