# Eidosc 0.8.0-alpha.1

## Eidos core single version line

- Merged Eidos language, Eidosc, and Std into a single version domain anchored at `0.8.0-alpha.1` (governance decision `core-single-version-line-2026-08-04`): the language contract, compiler implementation, and embedded standard library now ship under one version number, carried by the tutorial `eidos-v*` and Eidosc `eidosc-v*` release identities.
- Unified the authority sources (`docs/tutorial/eidos-language.toml`, `eng/Eidosc.Version.props`, `eng/Std.Version.props`) with consistency enforced by `scripts/versioning/verify-versions.ps1` and workspace `scripts/verify-ecosystem-lock.ps1`.
- Retired the independent Std release workflow; Std ships with the compiler and no longer has a separate release identity. Eidosup and Eidosc.Bindgen remain independently versioned.
- Removed the cross-component compatibility range from the language manifest; `compatibility.json` `language.default` now always equals the toolchain version, and `language.supported` retains the old-language migration range.
- Updated the embedded Std package manifest and `EidosStdVersions.Current` to the unified version.

> The accumulated 0.7/0.8 compiler work (fragments under `changelogs/0.7.0-alpha.1/` and `changelogs/0.8.0-alpha.1/`) is consolidated into this entry by the release PR that finalizes the version.
