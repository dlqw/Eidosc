# Native ownership lowering and automatic reuse

- Classification: feature
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.8.0-alpha.1`

## Added

- Enabled native drop insertion across overwrite, branch, loop, tail-call, partial-move, intrinsic, FFI, and external-declaration paths, with path-sensitive ownership transfer and balanced destruction.
- Added scalar-tag lowering for closed payloadless ADTs and inline value ABI lowering for small `Copy` records, including cache serialization and cross-function calls.
- Added compiler-owned destructive projection moves, copy/drop elision, record-update fusion, and unique-owner reuse preparation.
- Added consuming runtime-array primitives and fusion paths for slicing, prefix take, prepend, append, self-extension, and right-buffer growth.
- Added runtime record retainer registration so copy-on-write updates preserve managed fields when a shared record must be cloned.

## Changed

- Record updates and sequence construction now reuse uniquely owned storage when legal and preserve copy-on-write semantics when aliases exist.
- Native LLVM lowering statically resolves runtime type IDs for inline records and keeps aggregate move sources initialized for later cleanup.
- Windows LTO links through LLVM `lld`, matching the selected native optimization pipeline.

## Correctness

- MIR liveness and drop placement now distinguish upward-exposed uses, borrow aliases, consuming calls, and bodyless declarations.
- Incremental MIR payloads and fingerprints preserve constructor layout, scalar representation, `Copy` evidence, and record-update metadata.
- Added native allocation-balance, runtime copy-on-write, branch/loop, stack-promotion, ASAN, and long-running Snake regression coverage.
