# Seq header/data scalar replacement: inline array length for caller-owned arrays

- Classification: perf
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.8.0-alpha.1`

## Added

- `MirCallerOwnedArrayStorage.PromoteInline` marks stack-resident caller-owned
  array storages with a compile-time capacity and known unmanaged element
  layout as eligible for inline header/data lowering; the flag is serialized in
  the MIR function fingerprint so cache-hit and cache-miss codegen agree.
- `array_length` on a promoted array is lowered to an SSA load of the live
  array pointer's length header (with the runtime's NULL -> 0 semantics
  replicated branch-free), eliminating the `eidos_array_length` dispatch in
  caller-owned aggregate variants. The length is read through the aggregate's
  live pointer rather than the inline storage slot so arrays that have
  outgrown their inline capacity and moved to the heap stay correct.

## Changed

- The caller-owned aggregate specialization pass now propagates array storage
  metadata from a caller into the caller-owned variants it invokes (in
  addition to the existing callee -> caller direction), so promoted operations
  resolve inside parameter variants such as the hot `step`/`advance_state`
  loop of the snake GUI sample.
- `eidos_array_new_in_storage` size arguments are recomputed from the concrete
  element layout at lowering time so the inline storage slot and the wrapper
  aggregate layout always agree.

## Performance

- snake-gui benchmark: 5,000,000 steps checksum `2094999808` unchanged,
  steady-state allocation slope 0 (`alloc 21 / free 1` at 1M and 5M steps),
  median runtime ~140 ms vs ~178 ms with the dispatch retained (A/B on the
  same compiler).
- One `eidos_array_length` call per promoted aggregate array is removed in the
  hot variant; remaining dispatches live in non-caller-owned functions
  (array-parameter helpers such as `contains_pos`/`drop_last` and stdlib text
  joins) and are tracked as a follow-up.

## Tests

- `MirToLlvmConverterTests.SeqScalarization`: promoted length on the out
  variant's own array local and on a group field projection both lower to the
  live-pointer header load with the NULL guard and no runtime call.
