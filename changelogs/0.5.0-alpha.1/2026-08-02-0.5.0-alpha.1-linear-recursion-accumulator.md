# Linear recursion accumulator transform

- Classification: feature
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.5.0-alpha.1`

## Added

- Added `LinearRecursionAccumulatorPass` to the default MIR optimization pipeline for the exact integer recurrence `F(n) = F(n - 1) + F(n - 2)` with the canonical `n < 2` base case.
- Rewrites proven-safe matches into an accumulator loop with one recursive call per iteration, while leaving every non-canonical shape unchanged.

## Correctness contract

- Requires structured self-call identity, canonical integer and Boolean types, a trusted pure/non-panicking effect summary, exact CFG and dominance relationships, and a strict instruction whitelist.
- Rejects extra calls, stores, drops, unsupported arithmetic, use-before-definition, ambiguous same-name calls, and functions carrying incompatible ownership or ABI metadata.
- Preserves the complete `MirFunc` metadata contract and Eidos unchecked integer overflow behavior.

## Verification

- Added positive IR-shape coverage requiring one self call and a loop back edge.
- Added negative proof-boundary coverage and optimized-versus-original differential evaluation across representative inputs, including overflow behavior.
