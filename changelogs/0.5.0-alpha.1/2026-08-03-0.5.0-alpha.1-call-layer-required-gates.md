# Required call-layer optimization gates

- Classification: none
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Coordination target: `0.5.0-alpha.1`

## Added

- Added a cross-platform required-test shard runner that parses TRX counters and fails when a filter selects zero tests, preventing misspelled or stale filters from silently passing CI.
- Added Windows and Ubuntu shards for constant-call folding termination, recurrence proof and semantic equivalence, MIR inlining, caller-owned escape proofs, LLVM call attributes, deterministic native checksum equivalence, LLVM IR shape, and native allocation counts.
- Added an Ubuntu-only AddressSanitizer shard for caller-owned aggregate stack lifetime validation.
- Added a deterministic native Fibonacci checksum gate that compiles and runs the same program with MIR optimization disabled and enabled, requiring both results to match the expected checksum.
