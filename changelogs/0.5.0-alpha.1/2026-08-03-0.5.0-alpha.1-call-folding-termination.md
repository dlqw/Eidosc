# Constant-call folding termination and memoization

- Classification: fix
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.5.0-alpha.1`

## Fixed

- Made the constant-call evaluator charge one shared deterministic budget for calls, basic-block entries, MIR instructions, terminators, and control-flow transitions, preventing empty `goto` and constant-`switch` loops from hanging compilation.
- Added in-progress cycle detection for recursive calls with unchanged constant arguments and memoized completed results by structured function identity, argument type, and argument value, while replaying their semantic step cost so budget decisions stay deterministic and independent of cache warm-up order.
- Propagated known constants through `MirCopy`, allowing nested pure calls separated by a copy to fold without losing the tracked value.

## Tests

- Covered empty self-loops, two-block loops, constant-switch loops, non-progressing recursion, recursion depth limits, repeated recursive subproblems, repeated identical calls, and copy-separated nested calls.
- Added constant-call folding and effect-summary trust/pipeline tests to the required Windows and Ubuntu CI suite.
