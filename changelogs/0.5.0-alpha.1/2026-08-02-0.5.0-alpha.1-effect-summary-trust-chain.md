# HIR effect summary trust chain and pure-call consumption

- Classification: feature
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.5.0-alpha.1`

## Added

- Made HIR effect summaries a trusted fact for optimization: a function with an inferred summary stays trusted even when a callee lacks a summary (missing summaries only widen the conservative memory/panic flags, which still gate elimination), so unknown callees no longer poison whole call chains.
- Included the declared `need` upper bound when deriving the trusted effect row, so functions that declare an effect remain effectful even when their body infers nothing (previously an empty declared-effect body could be treated as pure and its calls eliminated).
- Added compile-time folding of pure calls with all-constant arguments, including terminating recursive calls (bounded by depth and step budgets), via a small MIR evaluator.
- Registered the first `Benchmark`-category regression gate asserting the linear-recursion accumulator shape (single self call inside a loop with a back edge).

## Changed

- `ConstantFolding` now consumes function optimization summaries; DCE/CSE/LICM elimination and reuse now apply to ordinary user functions whose HIR summaries are pure and deterministic.
- MIR entry points fail fast when the effect inferer is missing instead of silently degrading every summary to unknown.
