# MIR inlining soundness and ownership preservation

- Classification: fix
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.5.0-alpha.1`

## Fixed

- Re-enabled the default MIR inlining pass with trusted pure-effect summaries and exact single-entry, single-return control-flow validation.
- Limited the active transform to primitive and structurally proven copy-like locals and results; managed-value inlining remains behind the call boundary until the optimizer can prove that remapped moves and drop insertion are equivalent.
- Preserved value transfer for local and projected arguments and returns, including move-out loads for projected places and complete caller function metadata after rewriting.
- Rejected unsupported ABI and semantic boundaries, including generic, runtime-word, caller-owned aggregate, trait-dispatch, constructor, borrowed-argument, Unit call-sugar, cross-module, parameter-dereference, intrinsic, FFI, task, text, console, and closure cases.
- Prevented local and temporary identifier collisions, partial-call expansion, argument/return type mismatches, and ambiguous function identity resolution.

## Verification

- Added unit coverage for the managed ownership proof boundary, candidate eligibility, call-shape validation, metadata preservation, Unit and borrowed-call boundaries, and default pass ordering.
- Added optimized MIR shape coverage plus native managed-record, runtime-array allocation-balance, and caller-owned aggregate smoke tests, and promoted them into the stable required CI suite.
