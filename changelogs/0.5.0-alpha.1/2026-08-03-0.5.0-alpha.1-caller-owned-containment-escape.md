# Caller-owned aggregate containment escape safety

- Classification: fix
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.5.0-alpha.1`

## Fixed

- Replaced the caller-owned parameter alias closure with a field-sensitive provenance analysis using `Untracked`, `DirectParamDerived`, `ContainsParamDerived`, `Escaped`, and `Unknown` states.
- Propagated parameter-derived values through aggregate fields, copies, moves, loads, calls, returns, branches, loops, constructors, closures, FFI, and unknown operations using a CFG fixed point.
- Forced the heap fallback whenever an aggregate containing caller-stack-backed storage can escape through a return, retaining call, indirect call, external function, runtime-array store, dereference, drop, or unsupported operation.
- Preserved caller-owned promotion when a callee stores the value in one aggregate field but only reads and returns an unrelated field.

## Tests

- Added MIR regressions for returned containers, FFI container escape, branch joins, same-field reloads, and unrelated-field reads.
- Added a Linux AddressSanitizer native test with stack-use-after-return detection enabled.
- Kept the existing nested-`Seq` zero-heap-allocation native gate.
