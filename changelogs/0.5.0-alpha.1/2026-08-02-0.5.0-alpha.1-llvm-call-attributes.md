# Sound native call attributes

- Classification: feature
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.5.0-alpha.1`

## Added

- Added `noundef` to ordinary integer and floating-point parameters whose Eidos ABI guarantees a defined scalar value.
- Added `nounwind` inference as a greatest-fixed-point analysis over the lowered LLVM call graph.

## Correctness contract

- Runtime and LLVM intrinsics are trusted as non-unwinding; external FFI declarations, unresolved targets, and indirect calls conservatively prevent `nounwind` from propagating to their callers.
- Compiler-synthesized entry wrappers, closure invoke helpers, ADT destructors, retainers, and module initialization functions participate in the same lowered call-graph analysis.
- Runtime-word ABI parameters are excluded from `noundef` because their integer slots may carry arbitrary bit patterns.
- Full-module and selected-function conversion preserve identical attribute-group IDs, parameter attributes, calling conventions, and function fragments; the fingerprint/fragment schemas were advanced to invalidate stale cached fragments.
- Internal calls retain the default C calling convention because the evaluated `fastcc` experiment did not show a stable benefit.

## Verification

- Added recursive-SCC, runtime-intrinsic, FFI, unresolved and indirect-call boundaries, synthetic helper coverage, full/partial fragment equivalence, and LLVM verifier checks.
