# Sound LLVM call attribute inference

- Classification: fix
- Latest immutable Eidosc release: `0.4.0-alpha.3`
- Target Eidosc version: `0.5.0-alpha.1`

## Fixed

- Replaced unconditional `nounwind` annotation with a greatest-fixed-point analysis over the lowered LLVM call graph. Direct internal and runtime-intrinsic call chains remain eligible, while FFI calls, unresolved declarations, and indirect calls conservatively prevent the attribute from propagating to their callers.
- Applied the same inference to compiler-synthesized entry wrappers, closure invoke helpers, ADT destructors, retainers, and module initialization functions instead of leaving them unannotated.
- Preserved full-module and selected-function conversion equivalence by carrying conservative MIR summaries for unselected callees and reserving attribute-group IDs consistently across both paths.
- Kept `noundef` on ordinary scalar parameters while excluding runtime-word ABI parameters whose integer slots may carry arbitrary bit patterns.
- Made LLVM function fragments preserve every function attribute group, parameter attribute, and calling convention, and advanced the fingerprint/fragment schemas so stale cached fragments cannot be restored under the old contract.

## Verification

- Added call-graph fixed-point tests covering recursive SCCs, runtime intrinsics, FFI boundaries, indirect calls, scalar ABI contracts, and repeated inference.
- Added production-path integration coverage for pure entry wrappers, transitive FFI boundaries, managed ADT lifecycle helpers, direct closure helpers, and indirect closure dispatch.
- Added required CI coverage for LLVM attribute emission, function fingerprints, selected conversion, and incremental fragment restore.
