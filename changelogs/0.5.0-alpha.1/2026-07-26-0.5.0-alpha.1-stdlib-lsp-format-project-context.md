# Eidosc 0.5.0-alpha.1 Std LSP, formatter, and project-context fixes

- sync-id: `eidosc-2026-07-26-stdlib-lsp-format-project-context`
- Made parser-only formatting validation stop before import loading, so formatting stdin no longer fails because semantic imports are unavailable.
- Aligned the query-driven LSP pipeline with normal compilation for physical Std module identity, implicit Prelude injection, same-package imports, module members, ADT constructors, signature-only callables, and generated instance identity.
- Added trusted toolchain-source grants for opened physical Std files without allowing arbitrary lookalike paths to acquire compiler-internal privileges.
- Added LSP workspace-folder and explicit active-project context support, and invalidated semantic snapshots when that context changes.
- Added a long-lived query-session regression audit covering every distributed physical Std source file.
