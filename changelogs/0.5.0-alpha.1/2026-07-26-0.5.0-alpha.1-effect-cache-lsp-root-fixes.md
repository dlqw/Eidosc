# Effect inference, cache restore, and stdlib LSP fixes

- Infer effective effect rows for body-bearing functions that omit `need`, while retaining explicit clauses as checked upper bounds.
- Expose inferred rows through IDE snapshots, LSP inlay hints, and a materialize code action.
- Treat physical bundled standard-library sources as compilable/cacheable sources rather than already-materialized semantic/MIR artifacts; missing restore payloads now compile, and cold builds skip fruitless per-module restore work.
- Preserve compiler package identity and compiler-owned source grants when Query/LSP opens a physical standard-library file.
- Publish only diagnostics owned by the active LSP document.
- Align user-defined effect names with the compile-time `UpperCamelCase` naming tier.
