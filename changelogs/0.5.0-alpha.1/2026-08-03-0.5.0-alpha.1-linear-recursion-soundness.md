# Linear recursion transform soundness

- Require trusted, pure, deterministic, non-panicking, allocation-free and memory-free function summaries before regrouping Fibonacci-shaped recursive calls.
- Match the complete three-block recurrence data flow, including unique definitions, definition-before-use ordering and copy chains, so unrelated calls, stores, drops or arithmetic cannot be discarded by the rewrite.
- Restrict the transform to canonical `Int` operations and verify the accumulator identity under the current wrapping 64-bit runtime arithmetic.
- Preserve generic, intrinsic, ownership, caller-owned aggregate ABI and function identity metadata when replacing a MIR function body.
- Add unit, differential and LLVM-shape regression coverage to the required CI suite.
