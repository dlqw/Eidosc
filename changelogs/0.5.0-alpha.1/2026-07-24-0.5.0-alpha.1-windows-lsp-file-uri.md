# Eidosc 0.5.0-alpha.1：Windows LSP 文件 URI

- Fixed Windows LSP document URI conversion when VS Code percent-encodes the drive separator, preventing paths such as `D:\Project` from being interpreted as `D:\D:\Project`.
- Preserved the on-disk casing of existing Windows document file names and canonicalized published diagnostic URIs, preventing a stale `Main.eidos` URI from producing a false `S1105` warning for `main.eidos`.
- Added regression coverage for percent-encoded Windows drive file URIs and case-only document URI differences.
